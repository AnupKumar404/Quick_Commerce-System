# ⚡ DailyVeggies - 30-Minute Delivery Web Application
DailyVeggies is a high-performance, fast quick commerce platform designed to process instant grocery orders and coordinate hyper-local deliveries within a 30-minute window.

## 📦 Tech Stack

**Frontend:** React.js(JavaScript), Tailwind CSS, Redux-Toolkit
**Backend:** Spring Boot(Java), Spring Security, Spring Data JPA
**Databases and Storage:** PostgreSQL (Primary Data), AWS S3(Static files uploads)
**Tools:** Maven(Build Tool), Git
**Cloud:** AWS EC2

## 🚀 Getting Started

Follow these steps to set up the development environment on your local machine.

### Prerequisites

Ensure you have the following installed:
- OpenJDK(v21.x LTS or Higher)
- PostgreSQL(Local Instance or Docker Container)
- IDE(IntellijIDEA or VSCode)
